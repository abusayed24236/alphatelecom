# ALPHA TELECOM — WEBSITE README

1. ABOUT THE WEBSITE

---

Website Name: Alpha Telecom
Website Type: Online Services & Telecom Business Website

This website is designed to showcase Alpha Telecom's services and help customers contact the business directly through WhatsApp.

2. PROJECT FILES

---

index.html

* Contains the main structure and content of the website.

style.css

* Controls the website's design, colors, layout, animations, and responsive styling.

script.js

* Handles website interactions, navigation, animations, and other JavaScript functionality.

README.txt

* Contains project information and setup instructions.

3. HOW TO RUN THE WEBSITE

---

1. Keep index.html, style.css, and script.js in the same folder.

2. Double-click index.html to open the website in your browser.

3. For development, you can use Visual Studio Code with the Live Server extension.

4. WHATSAPP CONTACT

---

The website includes a WhatsApp chat button.

When a visitor clicks the button, WhatsApp opens with a pre-filled "Hi" message.

The visitor must press Send to send the message.

5. IMPORTANT NOTES

---

* Do not rename the project files unless you also update their references in the HTML.
* Keep all required files in the same project folder unless the file paths are updated.
* Test the website on both desktop and mobile devices after making changes.
* Make sure the WhatsApp contact number in index.html is correct.

6. TECHNOLOGIES USED

---

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons
